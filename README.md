# 线代智感

**面向线性代数学习的认知学习伙伴**

线代智感是一个由曾展宽主持、团队共同建设的教学智能体项目，基于智雅平台搭建。项目关注学生在学习过程中遇到的具体困难，探索如何提供恰当的支持，让学生继续独立思考。

> 学生卡在哪里？现在应该帮多少？什么时候应该停止帮助？

## 项目特点

- **区分学习需求**：围绕理解、解题、纠错与诊断，选择相应的学习支持路径。
- **提供分层帮助**：结合学生的当前表现，逐步调整提问、提示和必要的局部示范。
- **保留学生的思考空间**：依据新的作答动态调整帮助，在当前目标达到时及时退出。
- **重视教学行为的验证**：结合模拟对话、交叉复核与人工审校，持续改进系统。
